# 蓝牙定位实验报告总结

## 1. 实验目标

本次实验的核心目标，是验证蓝牙 RSSI 与距离之间的经验关系，并在此基础上完成室内与室外场景下的二维定位建模与轨迹估计。

整体思路可以概括为三步：

1. 先做 linear 实验，验证 RSSI 到 distance 的路径损耗模型是否可用。
2. 再做 indoor 和 outdoor 两个二维定位实验，把多个接收端的 RSSI 转换为距离并进行三边定位。
3. 随着版本演进，引入不同的轨迹平滑或全局优化策略，比较 raw 与 smoothed 的效果。

## 2. linear 实验：验证 RSSI 求距离的经验公式

在正式做二维定位之前，我们先通过 linear 实验验证路径损耗模型。这里的目标不是直接求位置，而是检验 RSSI 反推 distance 是否符合实验现象。

### 2.1 路径损耗模型

我们采用的经验公式为：

$$
\mathrm{RSSI}(d) = a - 10n\log_{10}(d)
$$

其中，$d$ 是距离，$a$ 和 $n$ 是通过实验数据拟合得到的参数。

反过来，由 RSSI 估计距离的公式为：

$$
\hat d = 10^{\frac{a-r}{10n}}
$$

其中 $r$ 是测得的 RSSI。

### 2.2 linear 实验中的 raw 与 smoothed

在 linear 实验中，raw 数据就是每个采样点按上式反推出的估计距离；smoothed 数据则是在 raw 的基础上做局部平滑，当前实现采用的是三点加权平均：

$$
\tilde d_i = 0.2\hat d_{i-1} + 0.6\hat d_i + 0.2\hat d_{i+1}
$$

两端点不参与平滑，直接保留原始估计值。

### 2.3 实验意义

linear 实验的结果说明，RSSI 与距离之间虽然存在明显噪声和偏差，但整体趋势可以用路径损耗模型描述。因此，在后续 indoor 和 outdoor 实验中，我们可以先把 RSSI 转成距离，再进一步做定位优化。

## 3. indoor / outdoor 实验：二维定位建模

在验证了距离公式后，我们进入 indoor 和 outdoor 两个二维定位实验。它们的基本建模方式一致：

1. 每个接收端都有一个固定锚点坐标。
2. 先对每个接收端分别拟合路径损耗参数。
3. 将观测到的 RSSI 转换为距离。
4. 根据多个锚点到发射端的距离，求解发射端的二维位置。

对于第 $i$ 个轨迹点，如果锚点坐标为 $a_k$，估计距离为 $d_{ik}$，则最基本的定位目标可以写成：

$$
\min_{x_i} \sum_k \left(\lVert x_i-a_k\rVert - d_{ik}\right)^2
$$

其中 $x_i$ 是第 $i$ 个点的二维位置。

### 3.1 raw 数据的含义

在 indoor 和 outdoor 中，raw 数据不是原始 RSSI，而是由 RSSI 反推距离后，再通过定位优化得到的点位结果。也就是说，raw 更接近“直接定位输出”，但仍然带有拟合误差和测量噪声。

### 3.2 smoothed 数据的含义

smoothed 数据是在 raw 的基础上进一步约束轨迹连续性或平滑性得到的结果。不同版本对平滑的定义不同，但共同目标都是让轨迹更加自然，减少单点抖动。

## 4. 版本演进与优化办法

### 4.1 v1：逐点定位 + 指数移动平均

v1 的做法最直接：每个点独立做三边定位，得到 raw 轨迹；然后再对轨迹做指数移动平均作为 smoothed。

#### raw

对每个点独立求解：

$$
\min_{x_i} \sum_k \left(\lVert x_i-a_k\rVert - d_{ik}\right)^2
$$

这一步没有把相邻点关联起来，因此 raw 容易出现局部跳动。

#### smoothed

v1 使用指数移动平均：

$$
s_0 = p_0, \qquad s_i = \alpha p_i + (1-\alpha)s_{i-1}
$$

当前实现中，$\alpha = 0.45$。

这种方法实现简单，适合先看整体趋势，但它只是在后处理阶段平滑轨迹，不会改变定位优化本身。

### 4.2 v2：逐点定位 + 三点加权平滑

v2 仍然采用逐点三边定位作为 raw 的生成方式，但把平滑方式改成了中心三点加权平均。

#### raw

raw 的求解方式与 v1 相同，仍是逐点独立定位。

#### smoothed

对中间点使用：

$$
s_i = 0.2p_{i-1} + 0.6p_i + 0.2p_{i+1}
$$

这个版本的平滑比 EMA 更对称，也更适合只做可视化展示。

### 4.3 v3：全局轨迹优化 + 曲率惩罚

从 v3 开始，方法从“逐点定位后再平滑”转向“整条轨迹一起优化”。这是版本上的关键变化。

#### raw

v3 的 raw 不再是单点独立解，而是全局最小二乘结果，并加入较弱的曲率惩罚：

$$
\min_{\{x_i\}} \sum_i \sum_k w_k\left(\lVert x_i-a_k\rVert - d_{ik}\right)^2
+ \mu_{raw} \sum_{i=1}^{N-2} \lVert x_{i+1}-2x_i+x_{i-1}\rVert^2
$$

其中：

- $x_i$ 表示第 $i$ 个轨迹点。
- $a_k$ 表示锚点坐标。
- $d_{ik}$ 表示由 RSSI 反推的距离。
- $w_k$ 表示由拟合质量决定的权重。
- 第二项是二阶差分惩罚，用来抑制轨迹抖动。

#### smoothed

smoothed 仍然使用同一套全局优化框架，但把曲率惩罚系数增大：

$$
\min_{\{x_i\}} \sum_i \sum_k w_k\left(\lVert x_i-a_k\rVert - d_{ik}\right)^2
+ \mu_{smooth} \sum_{i=1}^{N-2} \lVert x_{i+1}-2x_i+x_{i-1}\rVert^2
$$

并且满足：

$$
\mu_{smooth} > \mu_{raw}
$$

因此，smoothed 轨迹比 raw 更平滑，也更符合连续移动的物理直觉。

### 4.4 v4：与 v3 同构，只是增加标注

v4 的数学方法与 v3 一致，仍然是“全局轨迹优化 + 不同强度的曲率惩罚”。区别只在于图像展示上增加了点位标签，方便检查每个点的对应关系。

换句话说，v4 没有改变 raw 或 smoothed 的生成公式，只是让结果更容易读。

## 5. indoor 与 outdoor 的共同结论

indoor 和 outdoor 虽然场景不同，但建模逻辑是一致的：

1. 先用 linear 实验验证 RSSI 到距离的经验公式。
2. 再把多个接收端 RSSI 转成距离。
3. 用三边定位或全局轨迹优化求出二维位置。
4. 根据版本不同，选择逐点平滑或全局曲率约束来得到更稳定的轨迹。

因此，整个实验的技术路线可以理解为：

**先验证距离模型，再做二维定位，再通过版本演进不断增强轨迹的稳定性与可读性。**

## 6. 简要总结

- linear 实验验证了 RSSI 到 distance 的经验公式，为后续定位提供了基础。
- indoor / outdoor 实验把 RSSI 转换为距离后，完成了二维位置估计。
- v1 使用逐点定位 + EMA。
- v2 使用逐点定位 + 三点加权平均。
- v3 / v4 使用全局轨迹优化，并通过曲率惩罚实现 raw 与 smoothed 的区分。

这条演进路线说明，实验从最基础的经验模型出发，逐步发展到更稳健的全局轨迹建模。
